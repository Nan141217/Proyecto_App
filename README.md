# Proyecto_App
El proyecto consiste en desarrollar un Sistema de Gestión para una Biblioteca Comunitaria, cuyo objetivo es facilitar la administración de recursos como libros y equipos disponibles para alquiler (computadoras, proyectores, tablets, etc.). El sistema permitirá a los administradores y usuarios realizar operaciones esenciales para el manejo eficiente de la biblioteca.![gestion de autores](https://github.com/user-attachments/assets/e1b26680-9857-45c8-bb72-85445f8579c5)
